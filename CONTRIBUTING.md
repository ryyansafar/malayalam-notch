# Contributing

Small project, few rules:

- `npm test` must stay green (`node --test test/`, no network, injected fakes).
- ES modules, Node >= 20, no new runtime dependencies without discussion.
- Keys live only in `.env` (git-ignored). Never print, log or commit them.
- Never fabricate Malayalam or dialect claims: show only what the API returns.
- The island follows `docs/DESIGN.md` exactly — check it before UI work.
